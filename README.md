# 脑控指令扩展

> 在 https://dexin64.github.io/Brainco/ 打开此页面

## 用作扩展

此仓库可以作为 **扩展** 添加到 MakeCode 中。

* 打开 https://makecode.microbit.org/
* 点击 **新项目**
* 点击齿轮图标菜单下的 **扩展**
* 搜索 **https://github.com/DeXin64/Brainco** 并导入

## 编辑此项目 ![构建状态标志](https://github.com/DeXin64/Brainco/workflows/MakeCode/badge.svg)

在 MakeCode 中编辑此仓库。

* 打开 https://makecode.microbit.org/
* 点击 **导入**，然后点击 **导入 URL**
* 粘贴 **https://github.com/DeXin64/Brainco** 并点击导入

## 关于本扩展

**脑控指令扩展** 是用于 MakeCode / micro:bit 的扩展库，可在 MakeCode 中导入后使用相关脑控指令积木。

## 使用方法

1. 打开 MakeCode micro:bit 编辑器：  
   https://makecode.microbit.org/

2. 新建一个项目。

3. 点击右上角齿轮图标。

4. 选择 **扩展**。

5. 在搜索框中输入：

   ```text
   https://github.com/DeXin64/Brainco
